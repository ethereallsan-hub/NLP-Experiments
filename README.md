# NLP Experiments

This repository contains my Natural Language Processing (NLP) laboratory experiments implemented using Python. The experiments demonstrate various NLP techniques including text preprocessing, named entity recognition, language modeling, topic modeling, text classification, and clustering.

---

# Experiments

- **EXP-1:** Text Preprocessing (Tokenization, Stemming & Lemmatization)
- **EXP-2:** Part-of-Speech (POS) Tagging
- **EXP-3:** Text Similarity & Document Clustering
- **EXP-4:** Information Retrieval using TF-IDF & LSA
- **EXP-5:** Legal Named Entity Recognition (NER)
- **EXP-6:** Biomedical Relation Extraction
- **EXP-7:** Language Modeling using N-Gram & Hidden Markov Model (HMM)
- **EXP-8:** Topic Modeling using Latent Dirichlet Allocation (LDA) & t-SNE Visualization
- **EXP-9:** Rule-Based vs Maximum Entropy (MaxEnt) Classification for Legal Documents
- **EXP-10:** Social Media Post Clustering using TF-IDF & K-Means
